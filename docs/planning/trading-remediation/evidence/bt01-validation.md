## Scope and test boundaries

The existing operator HTTP seam and existing pure indicator/profile functions are characterized. Production application modules are unchanged. The temporary test adapter strips exactly the legacy terminal startup branch and daemon signal registration, following the original audit approach; this is explicitly not proof of normal-import safety. A separate strict expected-failure test records that normal dashboard import attempts to start its scanner. BT02 owns the actual side-effect-free startup fix and replacement of this temporary adapter.

Tests use Flask's client and real disposable JSON/CSV files, not a mocked internal persistence helper. Provider behavior uses a fake external Spot boundary with observable simulated holdings. Credential environment is cleared, `.env` loading/read is blocked, bytecode writes disabled inside the adapter, socket/DNS/UDP transport and thread startup are blocked, and file/directory writes outside the disposable directory are rejected. Guard tests prove refusal without sending traffic or creating forbidden state. No provider/sandbox/live acceptance is claimed.

